Haetaan tietoa Helsingin kaupungin kansliasta:

STEP 1) Lisää ja asenna requests kirjasto
Käytä käskyä: pip install requests

STEP 2) kirjoita Python ohjelma, jolla haet tiedot.
https://stat.hel.fi:443/api/v1/fi/Hyvinvointitilastot/Lasten_ja_nuorten_hyvinvointi/1_Vaesto_ja_elinolot/VE01_lastenmaara.px

ja käytä json tietoa:
{
  "query": [
    {
      "code": "Ikä",
      "selection": {
        "filter": "item",
        "values": [
          "0-2-VUOTIAAT"
        ]
      }
    },
    {
      "code": "Vuosi",
      "selection": {
        "filter": "item",
        "values": [
          "23"
        ]
      }
    }
  ],
  "response": {
    "format": "json-stat"
  }
}

lopullinen koodi toimii seuraavasti:

import requests

url = "https://stat.hel.fi:443/api/v1/fi/Hyvinvointitilastot/Lasten_ja_nuorten_hyvinvointi/1_Vaesto_ja_elinolot/VE01_lastenmaara.px"

myobj = {
  "query": [
    {
      "code": "Ikä",
      "selection": {
        "filter": "item",
        "values": [
          "0-2-VUOTIAAT"
        ]
      }
    },
    {
      "code": "Vuosi",
      "selection": {
        "filter": "item",
        "values": [
          "23"
        ]
      }
    }
  ],
  "response": {
    "format": "json-stat"
  }
}

x = requests.post(url, json = myobj)

print(x.text)
